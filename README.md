## 🧠 Key Insights

1. Overall churn rate is **~26.5%** — over a quarter of customers leave.
2. **Month-to-month contracts** churn far more than 1-year/2-year contracts.
3. **New customers (tenure ≤ 3 months)** are the highest-risk group — over 60% churn within the first month.
4. Customers paying via **electronic check** churn at ~45%, nearly double the rate of automatic payment methods.
5. Model confirms EDA findings: **tenure, contract type, and monthly charges** are the top 3 predictors of churn.

## 💰 Business Impact

Targeting only the **top 20% highest-risk customers** (identified by the model) for a retention campaign — instead of discounting the entire customer base — is estimated to save significant monthly revenue at a fraction of the campaign cost. Full calculation is in the notebook (`Part 3: Business Impact Simulation`).

## 📋 Churn Playbook (Recommended Actions)

| Signal | Action |
|---|---|
| Tenure ≤ 3 months | Improve onboarding — tutorials, proactive check-ins |
| Month-to-month contract | Offer discount to switch to long-term plan |
| High predicted churn probability | Send retention offer / personalized discount |
| High monthly charges + high tenure | Treat as high-value — prioritize for premium support |

## ⚙️ How to Run

**1. Notebook (EDA + model training)**
Open `ChurnAnalysis_Enhanced.ipynb` in Google Colab or Jupyter, run all cells. This generates the three `.pkl` files needed by the app.

**2. Streamlit app (local)**
```bash
pip install -r requirements.txt
streamlit run app.py
```

**3. Deploy the app (free, public link for your resume/portfolio)**
- Push this repo to GitHub (include the `.pkl` files)
- Go to [share.streamlit.io](https://share.streamlit.io), connect your GitHub, select this repo, set main file to `app.py`
- You get a public URL to share with recruiters
